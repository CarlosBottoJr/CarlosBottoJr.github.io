# Currículo Web — Carlos Eduardo

Portfólio profissional feito com HTML, CSS e JavaScript.

## Publicar no GitHub Pages

1. Crie um repositório chamado `SEUUSUARIO.github.io`.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione a branch `main`.
5. Acesse `https://SEUUSUARIO.github.io`.

## Personalização

- Substitua os links do GitHub e LinkedIn em `index.html`.
- Para adicionar uma foto, coloque-a em `assets/` e substitua o bloco `.avatar`.
- Atualize projetos conforme seu portfólio evoluir.
